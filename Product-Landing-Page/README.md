# Cereal Killer Product Landing Page

Cereal Killer is a responsive product landing page for a spooky cereal brand. The site uses HTML and CSS only and keeps a Figma-inspired layout with a fixed header, hero section, problem section, product cards, facts table, join form, local video, and compact footer.

## Main Sections

- Fixed header and navigation
- Hero section with brand headline
- The Problem section
- Product card section
- The Facts table
- Join form and video section
- Footer

## Rubric Components

- `#header` is used on the page header.
- `#nav-bar` is fixed to the top of the viewport.
- `#video` is an HTML5 video element with controls.
- `#form` submits to `https://www.freecodecamp.com/email-submit`.
- `#email` uses `type="email"`, `name="email"`, and `required`.
- `#submit` is the form submit button.

## CSS Mechanics

- The hero content uses the `fade-up` CSS animation.
- Buttons and product cards use CSS transforms on hover.
- CSS Grid is used for the product cards, problem layout, and join/video layout.
- Media queries stack the product cards, problem section, and join/video section on small screens.
- The facts table uses horizontal scrolling on small screens.

## Accessibility

- Product and section images include descriptive alt text.
- The email input has a label for screen readers.
- The page uses semantic HTML elements including `header`, `nav`, `main`, `section`, `article`, and `footer`.
