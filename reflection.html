Course Reflection

This reflection looks back at the moments, challenges, design decisions, and skills that shaped my growth throughout Code + Design 1.

The Threshold

I have already been familiar with coding because of my Computer Science background. The main thing I needed to get used to with HTML and CSS was understanding how they connect and work together. I feel like it clicked for me during the Tribute Page project because I had to connect the styles with the HTML in a real project. Learning through practice was helpful, but being able to bring something I created to life by myself made me feel like I could really do it. From that point on, it became more about learning tips and tricks to create different layouts, effects, and functionality.

The Pit

The hardest assignment for me was the Field Guide project because learning responsive layout felt very fragile at first. If I got some of the spacing, widths, or percentages wrong, it could throw off the entire layout. I also struggled with changing my navigation from words to icons at certain screen sizes. Once I made the connection that an @media query worked almost like an if/else statement, it started to make more sense. After experimenting with max-width and min-width values, I realized responsive design was not as scary as I first thought.

The Pivot

My final portfolio compares pretty closely to my original Moodz and Vibes direction. I did not use as many colors as I had in my mood board because I started leaning toward a more minimal design with large typography. I also pivoted from the original fonts because I found other fonts that worked better for both my headings and body text. Even with those changes, I still kept the main idea of using large image backgrounds with text over them. Overall, the final design still connects back to the mood board while feeling cleaner and more focused.

The Process

I think I approached this class well with the time I set aside for it and the study habits I already had from previous coding classes. HTML felt easier to understand because it was more about hierarchy and structure instead of mathematical functions or data processes. The process felt like looking at a layout or image, then figuring out how to recreate it with HTML. CSS was harder because of the cascade and how one style could affect another part of the page. I learned a lot from the course, and if I were to take Code and Design 2, I would feel confident moving forward.

The Future

I see design and code impacting my future practice through a design-first, code-second mindset. Having a clear idea of what I want and being able to see it in Figma made the coding process much easier. Without that planning step, it would be harder because I would have to keep changing the code every time I did not like the design. That can also create new problems because changing one piece of code can accidentally break another part of the layout. Using design tools first helps me make decisions about layout, fonts, colors, and spacing before turning the design into code.
