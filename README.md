## Design Direction

For my portfolio, I pursued a dark athletic portfolio with a clean, personal-brand feel. The design uses a strong photo-based hero section, serif typography, a dark background, and simple project cards to connect my background as a student-athlete with my growth as a designer and coder.

| Element | Choice |
|---|---|
| Header Font | Roboto Serif |
| Body Font | Roboto Serif |
| Background | #313131 |
| Text | #FFFBFC |
| Secondary / Nav | #737373 |
| Light Accent | #D9D9D9 |
| Accent | #A51C30 |
